Panduan Operasional: Ping Mac / Windows ke Raspberry Pi via Pluto+ SDR

Panduan langkah demi langkah untuk mengalirkan paket ICMP ping antara Node 1 (Host PC) dan Node 2 (Raspberry Pi) melalui gelombang radio SDR (ADALM-Pluto) tanpa Wi-Fi, kabel LAN, maupun internet.

🎯 2. Skema Alokasi IP Address
⚠️

JANGAN TERTUKAR ANTARA IP USB DENGAN IP RADIO!

IP 192.168.2.1 adalah alamat internal kabel USB antara komputer dan board Pluto SDR miliknya masing-masing. Untuk menghubungkan PC ke Pi melalui radio, gunakan alamat virtual radio di subnet 192.168.50.x.

Lapisan Jaringan Perangkat / Interface Alamat IP Subnet Mask Fungsi & Keterangan
USB Link A (Host) Mac / Windows USB Gadget Adapter 192.168.2.10 255.255.255.0 Koneksi kabel data USB PC ke Pluto A
USB Link A (Host) Pluto+ SDR A (Firmware) 192.168.2.1 255.255.255.0 IP default firmware perangkat Pluto A
USB Link B (Pi) Pi USB Gadget (usb0) 192.168.2.10 255.255.255.0 Koneksi kabel data USB Pi ke Pluto B
USB Link B (Pi) Pluto+ SDR B (Firmware) 192.168.2.1 255.255.255.0 IP default firmware perangkat Pluto B
RF Radio Link Node 1 (Mac/Win) radio0 192.168.50.1 255.255.255.0 Alamat IP Radio Node 1 (Pengirim Ping)
RF Radio Link Node 2 (Pi) radio0 192.168.50.2 255.255.255.0 Alamat IP Radio Node 2 (Tujuan Ping)

1
Hubungkan & Konfigurasi Interface USB Pluto di Kedua Node
🖥️ Di Node 1 (Mac) 
# 1. System Settings -> Network -> USB 10/100 LAN
# 2. Set IP: 192.168.2.10, Subnet: 255.255.255.0
# 3. Tes koneksi USB ke Pluto A:
mm@macbook:~$ ping -c 2 192.168.2.1
📟 Di Node 2 (Raspberry Pi via SSH) 
# Aktifkan interface USB gadget usb0:
pi@raspberrypi:~$ sudo ifconfig usb0 192.168.2.10 netmask 255.255.255.0 up
# Tes koneksi USB ke Pluto B:
pi@raspberrypi:~$ ping -c 2 192.168.2.1

🩺 4. Tabel Diagnostik & Solusi Cepat (Cross-Platform)

🚫 Request Timeout

Firewall di host Raspberry Pi, Mac, atau Windows memblokir paket masuk ICMP Echo.

Linux: sudo ufw allow in on tun0
Windows: New-NetFirewallRule -DisplayName "Allow ICMPv4" -Protocol ICMPv4 -IcmpType 8 -Action Allow

⚠️ Driver USB Pluto di Windows

Perangkat PlutoSDR terdeteksi tanda seru kuning di Device Manager Windows.

Install driver resmi: PlutoSDR-M2k-USB-Drivers.exe

📉 CRC Error / Packet Loss Tinggi

Daya RF saturasi (*clipping*) atau osilator belum tersinkronisasi.

Pasang attenuator 30 dB atau turunkan tx_gain ke -20 dB

🔒 Device Busy Error

Proses script SDR sebelumnya masih berjalan dan mengunci port USB Pluto.

Mac/Linux: sudo pkill -f python
Windows: Stop-Process -Name python -Force
