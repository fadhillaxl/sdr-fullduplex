Panduan Operasional: Ping Windows PC ke Raspberry Pi via Pluto+ SDR

Panduan lengkap langkah demi langkah bagi pengguna Windows 10 / Windows 11 PC untuk mengalirkan paket ICMP ping ke Raspberry Pi melalui gelombang radio SDR (ADALM-Pluto) tanpa koneksi internet, router Wi-Fi, ataupun kabel Ethernet LAN.

🎯 2. Skema Alokasi IP Address
⚠️

JANGAN TERTUKAR ANTARA IP USB DENGAN IP RADIO!

IP 192.168.2.1 adalah alamat internal kabel USB antara PC dan board Pluto SDR miliknya masing-masing. Untuk menghubungkan Windows ke Pi melalui radio, gunakan alamat virtual radio di subnet 192.168.50.x.

Segmen Jaringan Perangkat / Adapter Alamat IP Subnet Mask Fungsi & Keterangan
USB Link 1 (Windows) Windows USB RNDIS Gadget 192.168.2.10 255.255.255.0 Koneksi kabel data USB Windows ke Pluto A
USB Link 1 (Windows) Pluto+ SDR A (Firmware) 192.168.2.1 255.255.255.0 Port kontrol IIO internal Pluto A
USB Link 2 (Pi) Pi USB Gadget (usb0) 192.168.2.10 255.255.255.0 Koneksi kabel data USB Pi ke Pluto B
USB Link 2 (Pi) Pluto+ SDR B (Firmware) 192.168.2.1 255.255.255.0 Port kontrol IIO internal Pluto B
RF Mesh Link Windows radio0 (Wintun) 192.168.50.1 255.255.255.0 IP Radio Node 1 (Pengirim Ping)
RF Mesh Link Raspberry Pi radio0 (tun0) 192.168.50.2 255.255.255.0 IP Radio Node 2 (Tujuan Ping)
🛠️ 3. Panduan Langkah Demi Langkah (Windows & Raspberry Pi)
1
Konfigurasi Interface USB Pluto di Windows & Pi
Hardware Link

Set alamat IP statis untuk adapter USB RNDIS di Windows (192.168.2.10) agar PC dapat berkomunikasi dengan Pluto SDR melalui port IIO 5337.

🪟 Windows (ncpa.cpl atau PowerShell)
# Cara Cepat via PowerShell (Admin):
PS> New-NetIPAddress -InterfaceAlias "*Pluto*" -IPAddress 192.168.2.10 -PrefixLength 24
# Tes konektivitas port IIO Pluto:
PS> Test-NetConnection 192.168.2.1 -Port 5337
TcpTestSucceeded : True
📟 Node 2 (Raspberry Pi via SSH)
# Aktifkan interface USB gadget di Pi:
pi@raspberrypi:~$ sudo ifconfig usb0 192.168.2.10 netmask 255.255.255.0 up
pi@raspberrypi:~$ ping -c 2 192.168.2.1
2 packets transmitted, 2 received, 0% packet loss

Konfigurasi Windows Defender Firewall untuk ICMP
Firewall Rule

Secara default, Windows memblokir paket ping yang masuk dari subnet virtual. Buka izin ICMPv4 dengan perintah PowerShell Administrator berikut:

🪟 Windows PowerShell (Run as Administrator)
PS> New-NetFirewallRule -DisplayName "Allow SDR ICMPv4 Ping" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -Action Allow
RuleName: Allow SDR ICMPv4 Ping | Enabled: True | Action: Allow
4
Uji Sinyal Gelombang RF 433 MHz (Stage 1)
Stage 1

Pancarkan nada kontinu (CW Tone) dari Windows dan ukur RSSI serta SNR di Raspberry Pi.

🪟 Windows (Transmitter TX)
PS> python scripts\tx.py --tone --freq 433000000 --gain -20
# Pluto A memancarkan gelombang 433.000 MHz...
📟 Raspberry Pi (Receiver RX)
pi@raspberrypi:~$ python scripts/rx.py --freq 433000000
[RX] Power: -42.5 dBFS | SNR: 25.4 dB | STATUS: LOCKED
5
Uji Paket Data Digital QPSK / OFDM (Stage 2–5)
Stage 5

Uji transmisi paket data biner dengan preamble, header, framing, dan validasi checksum CRC32.

🪟 Windows (Send Data)
PS> python scripts\link.py --role tx --data "HELLO PI FROM WINDOWS"
[TX] 22 bytes encoded (QPSK OFDM) -> Transmitted
📟 Raspberry Pi (Receive Data)
pi@raspberrypi:~$ python scripts/link.py --role rx
[RX] Frame Sync OK | CRC: VALID | Payload: "HELLO PI FROM WINDOWS"
6
Mengaktifkan Virtual Network Interface `radio0` (Stage 7)
Stage 7 TUN

Modem SDR kini dijadikan interface jaringan sistem operasi virtual (Wintun di Windows, tun0 di Linux).

🪟 Windows (PowerShell Admin)
PS> pluto-radio.exe link --tun --ip 192.168.50.1/24
[radio0] Wintun network adapter created (192.168.50.1/24)
[modem] Ready for bidirectional IP packets...
📟 Raspberry Pi (Terminal SSH)
pi@raspberrypi:~$ sudo .venv/bin/python -m pluto_radio.cli link --tun --ip 192.168.50.2/24
[radio0] tun0 interface created with IP 192.168.50.2/24
[modem] Listening for RF frames on 433.000 MHz...

🩺 4. Tabel Diagnostik & Solusi Masalah Khusus Windows
Gejala Masalah Penyebab Utama Solusi Praktis di Windows
Driver Pluto tanda seru kuning di Device Manager Driver RNDIS bawaan Windows belum terpasang atau terblokir Buka *Device Manager* → *Other Devices* → Klik kanan *PlutoSDR* → *Update Driver* → *Browse my computer* → *Let me pick* → Pilih Network Adapters → Pilih Microsoft → Remote NDIS Compatible Device.
ExecutionPolicy Restricted saat aktivasi .venv Kebijakan keamanan script PowerShell Windows Jalankan di PowerShell: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser.
Request timed out saat ping 192.168.50.2 Windows Defender Firewall memblokir paket ICMP Jalankan di PowerShell Admin:
New-NetFirewallRule -DisplayName "Allow ICMPv4" -Protocol ICMPv4 -IcmpType 8 -Action Allow
libiio.dll not found saat import pyadi-iio Pustaka C libiio belum terinstal di sistem Windows Unduh installer binary resmi libiio Windows Setup dan pastikan folder C:\Program Files\libiio terdaftar di PATH Windows.
Destination Host Unreachable Interface virtual Wintun belum diberi rute IP 192.168.50.1 Cek via ipconfig. Jika IP radio0 belum muncul, tambahkan manual via PowerShell Admin:
netsh interface ipv4 set address name="radio0" static 192.168.50.1 255.255.255.0
Packet loss tinggi (> 20%) Sinyal saturasi (kabel tanpa peredam) atau interferensi ISM Jika menggunakan kabel SMA, pasang attenuator 30 dB. Jika nirkabel, turunkan parameter gain transmisi: --gain -30.
Device or resource busy di Windows Ada proses Python sebelumnya yang mengunci koneksi USB IIO Matikan proses Python yang menggantung di PowerShell:
Stop-Process -Name python -Force
